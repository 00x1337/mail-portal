# بوابة البريد الإلكتروني الموحدة للشركات (Mail Portal)

بوابة تسجيل الدخول المخصصة لخدمة البريد الإلكتروني السحابي (Mailcow & SOGo) لجميع الشركات الأربع:
1. **شركة قافلة الغذاء لخدمات الإعاشة** (`@qafilatfood.sa`)
2. **شركة رواد التعمير والتنمية** (`@rowaddevelopment.sa`)
3. **شركة تموين الديار** (`@diyarsupply.sa`)
4. **شركة خطوط الإنشاء للمقاولات** (`@khotoutco.sa`)

---

## 🎯 المميزات الرئيسية
- **اختيار الشركة من قائمة منسدلة:** لا حاجة لكتابة الدومين الكامل يدوياً في كل مرة.
- **إدخال اسم الحساب فقط:** يكتب الموظف `gm` أو `procurement` أو `hr` أو `finance` أو `info` فقط، ويتم دمج الدومين تلقائياً وبدقة.
- **توجيه مباشر لبريد الويب:** بمجرد الدخول، يتم تحويل الموظف مباشرة إلى واجهة بريده الإلكتروني في SOGo Webmail.
- **إظهار/إخفاء كلمة المرور:** أيقونة عين تفاعلية لتسهيل إدخال وتأكيد كلمة السر.
- **دعم الدخول العام:** خيار لإدخال بريد كامل أو الدخول كمدير نظام (`admin`).
- **سكربت نشر تلقائي بنقرة واحدة (`./deploy.sh`):** يرفع التعديلات للسيرفر ويمسح الكاش ويعيد تشغيل الخدمة فوراً.

---

## 🚀 طريقة التعديل والنشر (Workflow)

### 1. التعديل على التصميم محلياً على جهازك:
- ملف واجهة الدخول الرئيسي: [`templates/user_index.twig`](templates/user_index.twig)
- ملف التصميم الأساسي: [`templates/base.twig`](templates/base.twig)
- التنسيقات المخصصة: [`css/`](css/)
- الشعارات والأيقونات: [`img/`](img/)

### 2. رفع التعديلات للسيرفر مباشرة:
قم بتشغيل سكربت النشر من سطر الأوامر داخل هذا المجلد:
```bash
./deploy.sh
```
يقوم السكربت تلقائياً بـ:
1. مزامنة القوالب والتنسيقات والصور إلى السيرفر (`148.113.251.156`).
2. تفريغ كاش Twig القديم لضمان ظهور التعديلات فوراً.
3. إعادة تشغيل حاويات Nginx و PHP-FPM.
4. إجراء فحص صحة وتأكيد نجاح النشر.

### 3. حفظ التعديلات في GitHub:
```bash
git add .
git commit -m "Update login portal design"
git push origin main
```
